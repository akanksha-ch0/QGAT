01 / Manifesto

Biological insight should not be buried in complex bioinformatics pipelines. We make genomic annotation tangible, accessible, and fast.

01

Tactile Animal QTLdb Mapping

Directly cross-reference chromosome positions against Animal QTLdb trait catalogs across Cattle, Goat, Sheep, Pig, Chicken, and Horse to pinpoint phenotypic associations instantly.

02

Dynamic Flanking Windows

Go beyond fixed gene boundaries. Support for SNP position markers with custom ±kb flanking radius expands the discovery window for regulatory elements and causal variants.

03

Unified Dual GTF Engine

Seamlessly digests both Ensembl and NCBI annotation formats, calculating exact overlap base pairs, percentages, and transcription start site (TSS) distances automatically.

04 / Methodology

The QGAT Workflow

01

Ingest Coordinates

Handles TSV, CSV, or BED files with automatic column alias detection (chr, chrom, pos, start), BOM removal, and space trimming.

02

Window Expansion

For SNP markers, computes symmetrical or asymmetrical flanking boundaries ([pos - window, pos + window]) to encompass potential promoter or regulatory elements.

03

QTLdb Intersection

Intersects regions with species-specific Animal QTLdb records, identifying trait classifications, PubMed citations, and candidate locus annotations.

04

Gene Model Overlap

Calculates overlap base pairs, percentage coverage, and distance to the Transcription Start Site (TSS) against Ensembl or NCBI GTF models.

05 / Terminal & SDK

Command-Line Interface

# 1. Install QGAT directly from GitHub
$ pip install git+https://github.com/akankshachoudhary/QGAT.git

# 2. Check installed version
$ QGAT --version
QGAT version 0.2.0
# Find overlapping QTLs with 50kb flanking window
$ QGAT qtl -i snps.tsv -species cattle -o output_qtls.tsv --window 50000

# BED-based or GFF-based lookup with trait filter
$ QGAT qtl -i gwas_hits.tsv -species goat -trait
# Annotate regions using custom GTF and feature filter
$ QGAT annotate \
    -i snps.tsv \
    -gtf Bos_taurus.gtf \
    -o annotated.tsv \
    --window 25000 \
    --feature gene
# Python SDK integration
from QGAT import annotate_regions

df = annotate_regions(
    input_file="snps.tsv",
    species="cattle",
    window=50000
)
print(df.head())
